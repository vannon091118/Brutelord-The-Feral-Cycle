# deposit-visuals

## deposit-visuals

Spiegel-Datei für `src/world/deposits/deposit-visuals.js`.

## Verantwortung

Die Splitterlage eines Vorratsfelds: alles aus dem Pool, nichts zufällig. Die Splitter
entstehen im Ring um den Vorrat und fliegen auf den grabenden Dungling zu; steht er auf der
Kachel, ist das Ziel deren Mitte.
