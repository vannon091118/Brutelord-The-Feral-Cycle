# AccountField

## accountfield

Spiegel-Datei für `src/ui/account/AccountField.jsx`.

## Verantwortung

Ein Feld der Anmeldung: Beschriftung und Eingabe gehören zusammen, deshalb umschließt das Label den
Input. `autoFocus` lässt das erste Feld beim Eintreffen den Fokus tragen, `invalid` markiert es für
Hilfsmittel, wenn der letzte Versuch gescheitert ist.
