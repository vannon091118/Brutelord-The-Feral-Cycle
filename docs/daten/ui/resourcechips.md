## resourcechips

Spiegel-Datei für `src/ui/ResourceChips.jsx`.

## Verantwortung

Die Werteplaketten des HUD: Essenz im Hive, der gebundene Rest, Raum und Etage.
Die zweite Plakette erscheint nur, wenn ein offener Bauplatz Essenz versprochen
hat — sie ist der sichtbare Teil der Regel, dass eine Zusage bindet. Sie reicht
den Kreislauf nur an die Etagenplakette durch, damit diese den bezahlten Abstieg
kennt — sie entscheidet nichts.
