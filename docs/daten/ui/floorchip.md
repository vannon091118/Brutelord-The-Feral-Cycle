Spiegel-Datei für `src/ui/FloorChip.jsx`.

## Verantwortung

Die Etagenplakette: auf welcher Tiefe steht der Hive, und geht es noch tiefer. Ohne Tiefe
gibt es keine Plakette — sie haengt an der Hinweiszeile, nicht an jeder Leiste, die schon
eine Plakette traegt.
