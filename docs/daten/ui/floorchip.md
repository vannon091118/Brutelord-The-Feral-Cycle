# FloorChip

## floorchip

Spiegel-Datei für `src/ui/FloorChip.jsx`.

## Verantwortung

Die Etagenplakette: auf welcher Tiefe steht der Hive, und geht es noch tiefer. Ohne Tiefe
gibt es keine Plakette — sie haengt an der Hinweiszeile, nicht an jeder Leiste, die schon
eine Plakette traegt. Ob der Abstieg offen ist, liest sie aus `descendOpen()` im Kreislauf:
frei bis zur freien Leiter, darunter nur gegen Blutstein. Sie entscheidet die Regel nicht —
sie fragt sie.
